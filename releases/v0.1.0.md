loc makes local coding-agent environments easier to set up and maintain. This is the first public release, under the MIT license, and the project is in early development.

## What's included

- Named profiles combining **Claude Code, OpenCode, or Aider with Ollama**.
- Hardware inspection and model recommendations based on estimated memory fit.
- Detection and reuse of existing installations and model layers.
- Setup, launch, diagnostics, profile import/export, and repository defaults.
- Model and tool updates, model rollback, storage inspection, and selective uninstallation.
- Direct agent argument forwarding: `loc run --continue` or `loc run daily --dangerously-skip-permissions`.
- Names-only model listing, command help, JSON output, and shell completion.

The recommended pairing is **Claude Code + a local Qwen Coder model** that fits your hardware.

## Installation

Requires an existing **Python 3.11+**. Download `install.py` from the assets below, then run:

**macOS / Linux**

```sh
python3 install.py
```

**Windows PowerShell**

```powershell
python install.py
```

The installer verifies the release wheel against `SHA256SUMS`, reuses an existing uv/pipx installation manager where available, or creates an isolated environment using your existing Python. If loc is already installed, it reuses that installation. Follow the printed PATH instructions if `loc` is not found in your terminal. Model weights are downloaded separately, only when required by the selected setup.

```sh
loc --version
loc models recommend
loc setup daily
loc run daily
```

For future versions, use `loc self update --check` and `loc self update`.

## Downloads

- `loc_coding-0.1.0-py3-none-any.whl`: Python package for supported platforms; not a bundled standalone executable.
- `loc_coding-0.1.0.tar.gz`: source distribution.
- `install.py`: standalone installer.
- `install.sh` / `install.ps1`: optional wrappers; download `install.py` into the same directory.
- `SHA256SUMS`: checksums for the release files.

## Validation and limits

- Automated tests cover Python 3.11 and 3.14 on macOS, Windows, and Linux.
- The release wheel and installer are checked in an isolated environment, including repeat installation, command availability, and uninstall preserving profile data.
- Live coding edits passed on Apple Silicon macOS with Claude Code, OpenCode 2, and Aider.
- Live Windows/Linux agent setup and OS-specific dependency installers still need validation.
- Full offline enforcement currently supports Claude Code and Aider on macOS. Normal local inference does not prevent agent tools from using the network.
- Model recommendations estimate fit; latency and coding quality vary with hardware, context, model, and task.
- No native Homebrew/WinGet package, bundled Python, or PyPI distribution is included.

Feedback and reproducible reports are welcome in [Issues](https://github.com/joaopedromago/loc/issues). Include your loc version, operating system, command, and relevant error, with private data removed.
